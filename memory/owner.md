# Owner

How the owner works with agents.

- The owner chats in Spanish. Artifacts, code and commits are in English.
- Gate H1 is the one approval. After it, work runs without the owner, except escalations.
- The owner reads a spec as an HTML page with interfig scenario figures, not as markdown in chat. Write about 80% in ASD-STE100.
- Design first, then code. Show one decision at a time, with a clear recommendation.
- Use the harness workflow to build the harness (dogfood).
- Give honest, adversarial review. Show real gaps, also in your own work.
- Use one branch per feature, named `NNN-slug`. Merge to `main` at the end. Do not push or merge unless asked.
- Be precise, not eloquent. One idea per sentence. Bold only what changes a decision.
- Do not claim a decision the owner did not make.
